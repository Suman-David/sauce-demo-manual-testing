# Test Plan – Sauce Demo

## 1. Introduction
This test plan defines the approach for manual functional testing of the Sauce Demo e-commerce application.

## 2. Objective
Validate the application's major user workflows and verify that they behave according to expected functionality.

## 3. Application Under Test
- Application: Sauce Demo (Swag Labs)
- URL: https://www.saucedemo.com/
- Browser: Google Chrome

## 4. Scope of Testing

### In Scope
- Authentication
- Product inventory
- Product sorting
- Product details
- Shopping cart
- Checkout
- Input validation
- Logout and access control

### Out of Scope
- Performance testing
- Security penetration testing
- API testing
- Payment gateway testing

## 5. Testing Approach
Manual testing using predefined test cases, including:
- Positive testing
- Negative testing
- Functional testing
- Basic access-control validation

## 6. Test Environment
- Operating System: Windows (tester environment)
- Browser: Google Chrome
- Application: Public Sauce Demo website

## 7. Entry Criteria
- Application is accessible.
- Valid test credentials are available.

## 8. Exit Criteria
- Planned test cases are executed.
- Test results are recorded.
- Defects, if any, are documented.

## 9. Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Report
- Test Summary Report
