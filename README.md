# Sauce Demo – Manual Testing Project

## Project Overview
A manual functional testing project on the Sauce Demo e-commerce application, focusing on authentication, inventory, shopping cart, and checkout workflows.

## Application Under Test
- **Application:** Sauce Demo (Swag Labs)
- **URL:** https://www.saucedemo.com/
- **Testing Type:** Manual Functional Testing
- **Browser:** Google Chrome

## Testing Objectives
- Validate authentication and access control.
- Verify product inventory and sorting.
- Test product details and cart functionality.
- Validate checkout workflows and input errors.
- Document test cases and execution results.

## Testing Scope
- Login and Logout
- Product Inventory
- Product Sorting
- Product Details
- Shopping Cart
- Checkout
- Checkout Validation
- Access Control
